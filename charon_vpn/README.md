# Charon VPN

Flutter client (Windows + Android) for Charon, a personal VPN built around
Xray-core (VLESS-Reality-Vision) plus a Rust tunnel core (`charon-core`) shared
across this app and the legacy `app/` (egui) client via `flutter_rust_bridge`.

See the repository root `CLAUDE.md` for full project context, architecture,
and roadmap.
